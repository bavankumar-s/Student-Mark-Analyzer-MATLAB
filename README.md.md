MATLAB Student Mark Analyzer 📊

A simple MATLAB project designed to analyze student marks and generate useful performance statistics.

📌 Project Overview

The Student Mark Analyzer is a MATLAB-based project that takes student marks as input and analyzes their academic performance. It demonstrates the use of MATLAB programming, calculations, conditional statements, and data analysis.

✨ Features

- Enter student marks
- Calculate average marks
- Identify the highest mark
- Identify the lowest mark
- Analyse student performance
- Display results clearly in the MATLAB Command Window

🛠️ Technologies Used

- MATLAB
- MATLAB Scripts
- Basic Data Analysis

🚀 How to Run

1. Open MATLAB or MATLAB Online.
2. Download or clone this repository.
3. Open "student_mark_analyzer.m".
4. Run the script.
5. Enter the required student marks when prompted.
6. View the analysis in the Command Window.

📊 Example Output

The program displays important information such as:

- Average marks
- Highest marks
- Lowest marks
- Overall performance

🎯 Purpose

This project was created to practice MATLAB programming and understand how computational tools can be used for simple academic data analysis.
